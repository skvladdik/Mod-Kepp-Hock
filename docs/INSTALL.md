
# Installation — Mod Kepp Hock

## Requirements
- Windows 10/11
- GTA V Enhanced
- ReShade

## Installation

1. Make a backup of your game configuration.
2. Download ReShade from its official website.
3. Select GTA5_Enhanced.exe.
4. Select DirectX 10/11/12.
5. Install the standard shader effects.
6. Copy KeppHock.ini into your preset folder.
7. Start GTA V Story Mode.
8. Open the ReShade overlay using Home.
9. Select KeppHock.ini.

## Removal

1. Close GTA V.
2. Remove the KeppHock.ini preset.
3. Use ReShade setup to uninstall ReShade.

## Important

This project is intended for single-player use.
Do not use modified game files in GTA Online.
